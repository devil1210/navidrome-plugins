# Feishin Karaoke & Better Lyrics Shaders

Plugin / script ejecutable para **Feishin Desktop (Electron)** que habilita:
1. **Karaoke Palabra por Palabra**: Resaltado sincronizado con tiempos milimétricos `<mm:ss.xxx>` y soporte completo para **notas sostenidas**.
2. **Better Lyrics Shaders**: Fondos animado de gradientes fluidos en 60 FPS inspirados en `better-lyrics/shaders`.
3. **Desenfoque de Profundidad**: Estética cristalina estilo Apple Music / YouTube Music.

## Instalación en Feishin Desktop

1. Copiar `feishin-karaoke.js` a la carpeta de recursos de Feishin Desktop:
   `C:\Users\<TuUsuario>\AppData\Local\Programs\feishin\resources\`
2. Agregar `<script src="feishin-karaoke.js"></script>` en `index.html` de Feishin.
